Como usar

Ir para hoje. use o botão flutuante “Ir para hoje” para pular direto para a leitura do dia.
Cartões de leitura. toque em cada card de leitura do dia (AT/NT/etc.) para abrir o capítulo direto na Bíblia Online.
Visão mensal. cada mês agora tem um calendário. Toque no dia para ir para a linha dele e marcar como feito.
Atraso. se estiver atrasado, o topo mostra quantos dias faltam e o botão “Colocar em dia” abre o pacote acumulado.
